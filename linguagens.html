Como reconhecer linguagens de programação

Cada linguagem deixa pistas no código: palavras-chave, símbolos e o jeito de marcar blocos. Aqui você vê o mesmo problema, calcular o fatorial de um número, em três linguagens, e um programa em Brainfuck para comparar.

Um código, várias linguagens

Python

def fatorial(n):
    return 1 if n <= 1 else n * fatorial(n - 1)
  • Dois-pontos no fim da linha e recuo para marcar o bloco.
  • Palavras-chave em inglês: def, return, if, else.

Leia por que a indentação é a sintaxe do Python.

Haskell

fatorial :: Integer -> Integer
fatorial 0 = 1
fatorial n = n * fatorial (n - 1)
  • Assinatura de tipos com :: e seta ->.
  • Casamento de padrões: um caso para o zero e outro para os demais números.
  • Sem chaves e sem return.

JavaScript

const fatorial = (n) => (n <= 1 ? 1 : n * fatorial(n - 1));
  • const e a função seta =>.
  • Operador ternário ? : no lugar do if.
  • Chaves e ponto e vírgula são comuns em outros trechos do código.

Brainfuck

++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
  • Este programa imprime Hello World!. Calcular o fatorial exigiria dezenas de linhas.
  • Só 8 símbolos: > < + - . , [ ].
  • Sem letras, sem nomes e sem números: tudo é uma fita de células e um ponteiro.
